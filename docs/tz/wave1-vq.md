# ТЗ агенту 3: кодек VQ 2×8, residual k-means на CPU

## Роль

Ты продумываешь **только** кодек B: additive VQ, группа 8, M=2 книги по 256 векторов dim 8, residual k-means по MSE весов. CPU, Go (потом). Без GPU, без faiss, без гессиана, без активаций X.

## Зафиксировано (не спорь)

- `W[n_out, n_in]` row-major. Векторы: группы по 8 вдоль `n_in`. Число векторов = `n_out * n_in_padded / 8`.
- M=2, B=8, k=256. Индексы uint8. Книга `codebook[M][256][8]` хранится **FP16**. Счёт k-means — float32.
- Reconstruct: `g ≈ C1[i1] + C2[i2]` покомпонентно float32, потом для verify оставляем float32.
- `n_in % 8 != 0` → паддинг нулями, логический shape в метаданных.
- Это **диагностика формата**, не качество чата. M=1 в v1 не делаем.
- Детерминизм: seed фиксируется в CLI (`--seed`, дефолт 0). k-means++ на подвыборке, затем Lloyd.
- Assignment **чанками**, не материализовать `(N, 256, 8)`.
- Пустые кластеры: респлит самого толстого (добавить малый шум с того же RNG).
- Итерации по умолчанию: 20. Можно `--iters`.
- Книга **на матрицу**, не на слой.

## Напиши файл `docs/spec/vq.md`

До мелочей. Обязательные разделы:

1. Формулы residual k-means (init → iterate → residual → вторая книга). Все тензорные формы.
2. k-means++ на подвыборке: размер подвыборки (64k или `min(N, 65536)`), как семплировать без полного shuffle огромного N (проход с резервуаром или страйд+seed).
3. Assignment чанка: `dist = ‖x‖² + ‖c‖² − 2 x Cᵀ` — распиши dtypes, не писать sqrt если не нужен. Argmin, ties → меньший индекс.
4. Update: суммы и счётчики. Пустые кластеры.
5. Когда останавливаться раньше 20 итераций (если задал — порог сдвига центров).
6. Упаковка `index[n_out, n_in/8, M]`: layout в памяти (последняя ось M, M=2 → два подряд uint8). Численный пример 1×16 весов → 2 индекса.
7. Книга FP16: порядок осей `[M, 256, 8]`, little-endian.
8. Пик памяти на матрице 4096×14336: сколько байт на чанк assignment при chunk=1e6. Рекомендуемый chunk.
9. Инварианты тестов без модели:
   - синтетические данные = ровно 4 разных вектора dim 8, повторённые → после достаточного Lloyd книга содержит их (с точностью FP16), MSE ≈ 0;
   - reconstruct(encode(W)) = C1[i1]+C2[i2] **бит-согласованно** с записанной книгой (не с оригиналом W);
   - оригинал vs reconstruct: MSE не хуже, чем у тривиального «одна книга случайных 256» на той же фикстуре (или просто MSE < var(W) на N(0,1) маленькой матрице).
10. Стык с CHR0: поля `group_size: 8`, `n_codebooks: 2`, `codebook_bits: 8`.
